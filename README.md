# Tic-Tac-Toe (Python) (in progress)

Simple Tic-Tac-Toe game developed as the final assignment of the **Python Essentials** course.

The program simulates a game between the user and the computer.

## Rules

- The computer plays with **X**
- The user plays with **O**
- The computer always starts and places **X in the center**
- The user chooses a position using numbers from **1 to 9**
